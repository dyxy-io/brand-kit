# DYXY brand kit

Official DYXY logos and colors for partners, press, integrations and community content.

## Logos

| Asset | Use on | SVG | PNG |
| --- | --- | --- | --- |
| Logo, light wordmark | Dark backgrounds | [svg](logos/svg/dyxy-logo-light-text.svg) | [png](logos/png/dyxy-logo-light-text.png) |
| Logo, dark wordmark | Light backgrounds | [svg](logos/svg/dyxy-logo-dark-text.svg) | [png](logos/png/dyxy-logo-dark-text.png) |
| Logo, all white | Photos, colored or busy backgrounds | [svg](logos/svg/dyxy-logo-white.svg) | [png](logos/png/dyxy-logo-white.png) |
| Mark | Avatars, favicons, small sizes | [svg](logos/svg/dyxy-mark.svg) | [png](logos/png/dyxy-mark.png) |
| Mark, white | Mark on colored or busy backgrounds | [svg](logos/svg/dyxy-mark-white.svg) | [png](logos/png/dyxy-mark-white.png) |

PNG files have transparent backgrounds. Full logos are 2048 px wide, marks are 1024 px wide. Use SVG wherever possible.

```css

```

All values are also available as [colors.json](colors.json).

## Usage guidelines

**Do**

- Keep clear space around the logo at least equal to the height of the mark's ear tips.
- Use the light wordmark on dark backgrounds and the dark wordmark on light ones.
- Write the name as **DYXY**, in capitals.

**Don't**

- Stretch, rotate, crop or skew the logo.
- Recolor the logo outside the provided variants, or add shadows, outlines or effects.
- Place the logo on backgrounds where it loses contrast.
- Combine the logo with other marks into a new lockup, or use it in a way that suggests DYXY endorses a product, service or person without written permission.
